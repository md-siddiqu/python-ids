# Python IDS – Real-Time Intrusion Detection System

A lightweight, Python-based Intrusion Detection System that captures live network traffic and detects:
- **SYN Flood attacks** – TCP SYN packets without ACK
- **ARP Spoofing** – IP-MAC address changes
- **DNS Spoofing** – Domain-to-IP mapping inconsistencies

## How to Run
```bash
sudo python3 ids.py
